description: comment lancer le serveur de développement (Vite)
---

Pour lancer l'application sur votre ordinateur :

1. Ouvrez un terminal dans le dossier du projet : `c:\Users\pompi\OneDrive\Bureau\Mes-Transports-2026\mes transports`
2. Tape manually la commande suivante :
   ```powershell
   npm run dev
   ```
3. Une fois lancé, ouvrez votre navigateur à l'adresse indiquée (généralement [http://localhost:5173/](http://localhost:5173/)).

> [!TIP]
> Laissez le terminal ouvert tant que vous travaillez sur l'application. Pour arrêter le serveur, faites `Ctrl + C` dans le terminal.
